# Sam Training PWA

## Deploy in 2 minutes with Vercel
1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to Vercel → New Project → import the repository.
4. Framework preset: Other.
5. No build command needed.
6. Deploy.

## Install on iPhone
1. Open the deployed URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open Sam Training from your Home Screen.

## Data
Workout data is stored locally in the browser using localStorage.
That means it persists on that device/browser, but does not sync between devices yet.
